# Local Lead Finder

Crie um Dashboard moderno para uma ferramenta de Prospecção de Leads de Negócios Locais. A tela deve ter: 1) Dois campos de entrada: 'Categoria do Negócio' e 'Cidade/Região'. 2) Um botão principal de 'Buscar Leads'. 3) Um estado de carregamento (spinner/progress bar) indicando que a busca está em andamento. 4) Uma tabela estilizada para exibir os resultados (Nome, Telefone, Endereço, Nota no Google e Site). 5) Um botão de 'Exportar para Excel' no topo da tabela. Use cores modernas (dark mode ou tons de azul/verde para passar confiança).
